
# Mealora 🍽️

Mealora is a modern React-based recipe finder web application that helps users discover delicious meals from different categories using the MealDB API. Users can explore recipes, watch YouTube cooking tutorials, browse meal categories, and save their favorite recipes for quick access.

## 🚀 Features

- 🔍 Search recipes by name
- 🍲 Browse recipes by categories
- 📂 Multiple recipe sections and meal organization
- ❤️ Favorite recipes functionality
- 🎥 YouTube cooking tutorial integration
- 📱 Responsive UI for desktop and mobile
- ⚡ Fast and modern React frontend
- 🌐 API integration with TheMealDB

---

## 🛠️ Tech Stack

### Frontend
- React.js

- Tailwind CSS
- React Router DOM

### API
- TheMealDB API

### Deployment
- Vercel / Netlify

### Testing
